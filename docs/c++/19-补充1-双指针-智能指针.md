# C++ 补充知识整理：\`vector\`、双指针、智能指针与内存模型

这几轮内容可以串成一条主线：

```
数组
  ↓
vector：自动管理的动态数组
  ↓
指针：保存对象地址
  ↓
双指针：保存指针的地址
  ↓
智能指针：自动管理对象生命周期
  ↓
多文件程序：把声明、实现和入口分开
  ↓
内存模型：理解对象、函数和数据如何存在
```

---

# 一、\`std::vector\`

## 1. `vector` 是什么？

```
#include <vector>

std::vector<int> numbers;
```

`vector` 是标准库提供的动态数组容器。

它不是原生数组：

```
int arr[3] = {1, 2, 3};
```

但它内部通常管理一段连续内存：

```
[ 1 ][ 2 ][ 3 ][ 4 ]
```

它可以自动：

* 增加长度
* 分配内存
* 移动元素
* 释放内存

---

## 2. 常用操作

```
std::vector<int> numbers;

numbers.push_back(10);
numbers.push_back(20);

std::cout << numbers[0] << '\n';
std::cout << numbers.size() << '\n';

numbers.pop_back();
```


| 操作           | 写法               |
| -------------- | ------------------ |
| 添加元素       | `push_back(value)` |
| 删除末尾元素   | `pop_back()`       |
| 当前元素数量   | `size()`           |
| 是否为空       | `empty()`          |
| 清空           | `clear()`          |
| 访问元素       | `numbers[i]`       |
| 检查边界后访问 | `numbers.at(i)`    |
| 预留容量       | `reserve(n)`       |
| 调整元素数量   | `resize(n)`        |

---

## 3. `size` 和 `capacity`

```
std::vector<int> numbers;
numbers.push_back(10);
```

* `size()`：当前有多少个元素
* `capacity()`：当前已经分配了多少空间

```
numbers.reserve(100);
```

表示提前预留空间，减少频繁扩容。

扩容时，\`vector\` 可能重新申请内存，因此原来的指针、引用和迭代器可能失效。

---

## 4. 二维数据的两种表示

### 嵌套 `vector`

```
std::vector<std::vector<int>> matrix;
```

每个内部 `vector<int>` 自己的元素是连续的，但不同的行分别管理：

```
第 0 行 -> 一段连续内存
第 1 行 -> 另一段连续内存
第 2 行 -> 另一段连续内存
```

因此：

* 行内通常连续
* 行与行之间不保证连续
* 每一行可以有不同长度

### 一维 `vector` 模拟二维数组

```
int rows = 2;
int cols = 3;

std::vector<int> matrix(rows * cols);
```

所有元素在同一个 `vector` 中，连续存储：

```
[0][1][2][3][4][5]
```

访问位置：

```
int index = row * cols + col;
matrix[index] = 10;
```

如果不再增加元素，只修改已有元素，地址会保持稳定。

---

## 5. `vector` 在内存中的结构

```
std::vector<float> values(100);
```

可以粗略理解为：

```
栈：
values
 ├── 数据指针
 ├── size
 └── capacity

堆：
[ float ][ float ][ float ] ...
```

`vector` 对象本身和它管理的数据不是同一个对象。

# 二、双指针

## 1. 基本结构

```
int value = 10;
int* p = &value;
int** pp = &p;
```

关系：

```
pp
 ↓
 p
 ↓
value
```


| 表达式   | 含义            |
| -------- | --------------- |
| `value`  | 对象的值        |
| `&value` | 对象地址        |
| `p`      | 保存`value`地址 |
| `*p`     | 访问`value`     |
| `pp`     | 保存`p`的地址   |
| `*pp`    | 取出`p`         |
| `**pp`   | 访问`value`     |

---

## 2. 双指针的主要用途

如果函数需要修改调用者的指针，就要传递指针的地址：

```
void allocate(int** p)
{
    *p = new int(100);
}
```

调用：

```
int* value = nullptr;

allocate(&value);

std::cout << *value << '\n';

delete value;
value = nullptr;
```

如果只传 `int*`，函数得到的是指针副本，无法修改外部指针本身。

---

## 3. 双指针的阅读方法

看到：

```
T** p
```

可以依次问：

1. `p` 保存的是什么？
2. `*p` 是什么？
3. 函数是否需要修改外部指针？
4. 它是否表示指针数组或多维结构？
5. 谁负责释放对象？

---

# 三、智能指针

普通指针：

```
int* p = new int(10);
delete p;
```

需要手动管理生命周期。智能指针把指针和所有权规则结合起来，自动释放资源。

头文件：

```
#include <memory>
```

---

## 1. `unique_ptr`

表示独占所有权：

```
std::unique_ptr<int> p = std::make_unique<int>(10);
```

离开作用域时自动释放对象。

不能复制：

```
// std::unique_ptr<int> p2 = p; // 错误
```

可以移动：

```
std::unique_ptr<int> p2 = std::move(p);
```

移动后，\`p\` 不再拥有对象。

可以引用它：

```
void modify(std::unique_ptr<int>& p)
{
    *p = 100;
}
```

引用不会复制智能指针，也不会增加所有权。

---

## 2. `shared_ptr`

表示共享所有权：

```
std::shared_ptr<int> p1 = std::make_shared<int>(10);
std::shared_ptr<int> p2 = p1;
```

多个 `shared_ptr` 共同管理同一个对象。最后一个所有者销毁时，对象才释放。

它有引用计数，因此比 `unique_ptr` 有更多开销。

---

## 3. `weak_ptr`

不拥有对象，只观察对象：

```
std::weak_ptr<int> weak = p1;
```

使用前需要调用 `lock()`：

```
if (auto p = weak.lock())
{
    std::cout << *p << '\n';
}
```

主要用于观察对象和打破 `shared_ptr` 循环引用。

---

## 4. 裸指针

裸指针就是普通指针：

```
int* p;
```

它只表示一个地址，不自动表示所有权。

```
int value = 10;
int* p = &value;
```

这里 `p` 只是观察 `value`，不能：

```
delete p;
```

看到裸指针时要问：

```
它是否拥有对象？
谁负责释放？
它会不会变成悬空指针？
```

智能指针也可以临时提供裸指针：

```
auto p = std::make_unique<int>(10);
int* raw = p.get();
```

`raw` 不能负责释放对象。

---

# 四、\`auto\`

`auto` 是类型推导关键字，不是无类型变量。

```
auto x = 10;
```

等价于：

```
int x = 10;
```

```
auto p = std::make_unique<int>(10);
```

等价于：

```
std::unique_ptr<int> p = std::make_unique<int>(10);
```

`auto` 必须初始化：

```
// auto x; // 错误
```

引用和常量通常需要显式写出：

```
auto& ref = value;
const auto& ref = value;
```

# 五、程序运行时的内存模型

可以使用下面的简化模型：

```
高地址
┌────────────────┐
│ 栈 Stack       │
├────────────────┤
│ 空闲区域       │
├────────────────┤
│ 堆 Heap        │
├────────────────┤
│ 静态数据区     │
├────────────────┤
│ 只读数据区     │
├────────────────┤
│ 代码区         │
└────────────────┘
低地址
```

这只是帮助理解的模型。C++ 标准更关注对象的生命周期和存储期。

## 1. 栈和自动存储期

```
void func()
{
    int x = 10;
}
```

`x` 通常位于栈上，函数结束时销毁。

## 2. 静态存储期

```
int global_value = 10;

void func()
{
    static int count = 0;
}
```

它们从程序开始到程序结束一直存在。

## 3. 堆和动态存储期

```
int* p = new int(10);
```

`p` 是一个指针变量，通常在栈上；\`new int(10)\` 创建的对象通常在堆上。

## 4. 函数

函数编译后变成机器指令，通常位于代码区。

## 5. 类和结构体

类型定义本身不是一个对象：

```
struct Point
{
    int x;
    int y;
};
```

实例才占用内存：

```
Point p{1, 2};
```

成员数据存储在对象内部，成员函数的代码通常只有一份。

## 6. 宏

```
#define SIZE 1024
```

宏在预处理阶段展开，运行时不存在一个叫 `SIZE` 的对象。

---

# 六、综合判断表


| 内容               | 通常情况                     |
| ------------------ | ---------------------------- |
| 局部变量           | 栈或寄存器                   |
| 全局变量           | 静态数据区                   |
| `static`局部变量   | 静态数据区                   |
| `new`创建的对象    | 堆                           |
| `vector`对象       | 所在作用域                   |
| `vector`管理的数据 | 通常在堆                     |
| 函数机器代码       | 代码区                       |
| 字符串字面量       | 只读数据区                   |
| 宏                 | 编译前处理，不属于运行时对象 |
| `unique_ptr`       | 自身是对象，管理另一个对象   |
| 裸指针             | 保存地址，不自动管理生命周期 |

# 七、案例题：多文件学生成绩管理程序

## 题目

实现一个简单的学生成绩管理程序，将代码拆分为：

```
student.h
student.cpp
main.cpp
```

程序需要：

1. 保存多个学生
2. 添加学生
3. 计算平均分
4. 找出最高分学生
5. 使用智能指针创建学生对象
6. 使用双指针实现“创建并返回对象”
7. 使用 `vector` 保存学生和成绩
8. 使用头文件声明、源文件实现、\`main.cpp\` 作为入口

---

## 文件一：\`student.h\`

要求声明：

```
#ifndef STUDENT_H
#define STUDENT_H

#include <string>
#include <vector>
#include <memory>

struct Student
{
    std::string name;
    std::vector<double> scores;
};

double average_score(const Student& student);

Student* find_top_student(
    const std::vector<Student*>& students
);

void create_student(
    Student** result,
    const std::string& name,
    const std::vector<double>& scores
);

#endif
```

思考：

* 为什么函数参数使用 `const Student&`？
* 为什么 `create_student` 使用 `Student**`？
* `Student*` 是否表示拥有对象？
* 谁负责释放这些学生对象？

---

## 文件二：\`student.cpp\`

实现：

### 1. 平均分函数

```
double average_score(const Student& student)
{
    // 计算 scores 中所有元素的平均值
}
```

注意：

* 不要修改 `student`
* 如果没有成绩，返回 `0.0`
* 使用 `vector::size()`

### 2. 最高分学生

```
Student* find_top_student(
    const std::vector<Student*>& students
)
{
    // 返回平均分最高的学生地址
}
```

注意：

* 返回的是观察指针
* 不要在函数中 `delete`
* 空数组时返回 `nullptr`

### 3. 双指针创建对象

```

    Student** result,
    const std::string& name,
    const std::vector<double>& scores

{
    // 使用 new 创建 Student
    // 将地址写入 *result
}
```

核心思路：

```
*result = new Student{name, scores};
```

---

## 文件三：\`main.cpp\`

程序流程：

```
#include "student.h"
#include <iostream>

int main()
{
    std::vector<Student*> students;

    Student* student1 = nullptr;
    Student* student2 = nullptr;

    create_student(
        &student1,
        "Alice",
        {90.0, 85.0, 92.0}
    );

    create_student(
        &student2,
        "Bob",
        {78.0, 88.0, 80.0}
    );

    students.push_back(student1);
    students.push_back(student2);

    Student* top = find_top_student(students);

    if (top != nullptr)
    {
        std::cout << top->name << '\n';
        std::cout << average_score(*top) << '\n';
    }

    delete student1;
    delete student2;

    return 0;
}
```

编译：

```
g++ main.cpp student.cpp -o student_app
```

# 八、案例题的改进版本

上面的版本使用了裸指针，释放工作需要手动完成。可以改成智能指针：

```
std::vector<std::unique_ptr<Student>> students;
```

创建对象：

```
students.push_back(
    std::make_unique<Student>(
        Student{"Alice", {90.0, 85.0, 92.0}}
    )
);
```

查找函数可以接收：

```
const std::vector<std::unique_ptr<Student>>& students
```

访问对象：

```
students[i]->name
```

这样就不需要：

```
delete student1;
delete student2;
```

因为 `vector` 销毁时，内部的 `unique_ptr` 会自动释放每个 `Student`。

# 九、案例题学习目标

完成这个案例后，你应该能解释：

```
student.h
    保存声明和结构体定义

student.cpp
    保存函数实现

main.cpp
    保存程序入口和调用逻辑

vector
    保存可变数量的学生或成绩

Student**
    让函数修改外部的 Student* 指针

unique_ptr
    自动管理 Student 对象生命周期

const Student&
    只读访问，避免复制对象

Student*
    可能只是观察指针，不一定拥有对象

main()
    程序的入口函数
```

推荐完成顺序：

1. 先用 `Student*` 和 `delete` 完成基础版本
2. 再改成 `std::unique_ptr<Student>`
3. 对比两个版本的内存管理方式
4. 使用调试器观察指针地址、对象地址和 `vector` 内容
5. 尝试解释每个对象的生命周期
