# 第一部分：函数可以有不同的形式

## 1. `void`：函数可以不返回结果

### 1.1 先回忆有返回值的函数

```cpp
int add(int a, int b)
{
    return a + b;
}
```

调用时：

```cpp
int result = add(3, 5);
// result 得到 8
```

这里 `add` 的任务是**算出一个数并交给调用者**，因此：

- 函数开头写 `int`：返回值的类型是 `int`。
- `return a + b;`：把计算结果返回给调用者，同时结束本次函数调用。

### 1.2 如果任务只是打印文字呢？

比如希望反复执行“向终端打招呼”：

```cpp
#include <iostream>
#include <string>

void say_hello(std::string name)
{
    std::cout << name << "，你好！\n";
}

int main()
{
    say_hello("Tom");
    say_hello("Alice");
    return 0;
}
```

输出：

```text
Tom，你好！
Alice，你好！
```

这时我们的目的不是得到一个整数，而是**让函数完成打印动作**。

- `void`：函数**不向调用者提供结果值**。
- `say_hello`：函数名。
- `(std::string name)`：需要一个名字作为参数。
- `{ ... }`：真正执行的代码。

**重要区别**：“无返回值”不等于“没产生效果”；打印文字、写文件、修改允许访问的对象等，都是函数的效果。

### 1.3 `void` 就完全不能写 `return` 吗？

不是。它可以不写 `return`，也可以写**没有值的 `return;`** 提前结束。

```cpp
void print_positive(int x)
{
    if (x <= 0) {
        return;  // 提前结束本次函数调用
    }

    std::cout << x << '\n';
}
```

请区分：

```cpp
void f() { return; }      // 可以：直接结束
// void f() { return 10; } // 不可以：void 不返回一个 int 值
```

对于普通非 `void` 函数，如果执行路径需要返回结果，就应该写出对应的 `return 值;`。`main()` 是一个特例：走到结尾等价于 `return 0;`。

### 1.4 Python 对比

```python
def say_hello(name):
    print(f"{name}，你好！")

x = say_hello("Tom")
print(x)  # None
```

Python 函数没写 `return` 时，调用表达式的结果是 `None`。**C++ 的 `void` 则没有一个可以拿来赋给普通变量的返回结果**：

```cpp
say_hello("Tom");       // 正确
// int x = say_hello("Tom"); // 错误：没有 int 返回值
```

## 2. 函数也可以没有参数，但括号 `()` 仍然要写

课程示例是把一段固定操作封装成函数。比如：

```cpp
#include <iostream>

void print_five_times()
{
    for (int i = 0; i < 5; ++i) {
        std::cout << "Hello!\n";
    }
}

int main()
{
    print_five_times();
    return 0;
}
```

这里：

- 定义 `print_five_times()`：没有形参，不需要调用者提供数据。
- 调用 `print_five_times()`：执行函数内的五次输出。
- 即使没有参数，**括号也不能省略**。

把参数和返回值组合起来，函数有四种常见形式：

| 函数形式 | 例子 | 适合做什么 |
|---|---|---|
| 有参数、有返回值 | `int add(int a, int b)` | 根据输入求结果 |
| 有参数、无返回值 | `void print_num(int x)` | 根据输入执行动作 |
| 无参数、有返回值 | `int get_five()` | 不需要输入，提供结果 |
| 无参数、无返回值 | `void show_menu()` | 固定地执行某个操作 |

**先记住**：有无参数和有无返回值是两件独立的事。

## 3. 一个函数可以调用另一个函数

课程截图里，在 `func_a()` 中调用 `func_b()` 和 `func_c()`，这叫**函数嵌套调用**。

### 3.1 从 Python 理解

```python
def get_a():
    return 10

def get_b():
    return 20

def total():
    return get_a() + get_b()

print(total())  # 30
```

C++ 也是同样思路：

```cpp
#include <iostream>

int get_a()
{
    return 10;
}

int get_b()
{
    return 20;
}

int total()
{
    int x = get_a();
    int y = get_b();
    return x + y;
}

int main()
{
    std::cout << total() << '\n'; // 30
    return 0;
}
```

### 3.2 按执行顺序走一遍

```text
main() 需要 total() 的结果
    ↓
进入 total()
    ↓
调用 get_a()，得到 10，存入 x
    ↓
调用 get_b()，得到 20，存入 y
    ↓
计算 10 + 20，return 30
    ↓
回到 main()，打印 30
```

这就是“函数调用可以层层嵌套”。

**两个不要混淆的概念**：

- **嵌套调用**：在一个函数的代码中**使用**别的函数。✅
- **嵌套定义**：直接在 `main()` 的花括号里再写一个普通具名函数的完整定义。普通 C++ 函数不支持这种写法。❌

比如以下写法不是合法的普通 C++：

```cpp
int main()
{
    // int helper() { return 10; }  // 不允许在这里直接定义具名普通函数
    return 0;
}
```

嵌套调用的层数也不是无限的：过深的函数调用或递归，可能导致调用栈空间耗尽。**目前理解“一个函数可以调用另一个函数”即可**，递归以后专门学习。

# 第二部分：先弄懂“传参时到底把什么交给函数”

## 4. 回到最基础的三个动作：值、地址、按地址访问

你前面已经学过：

```cpp
int x = 10;
int* p = &x;
```

为了后面不混乱，先看这个表：

| 写法 | 你在操作什么 | 用这个例子理解 |
|---|---|---|
| `x` | 整数变量的值 | `10` |
| `&x` | 整数变量的地址 | 假设 `0x1000` |
| `p` | 指针变量保存的值（地址） | `0x1000` |
| `*p` | 顺着地址找到原对象，再访问它 | `10` |
| `&p` | 指针变量 `p` **自身**的地址 | 假设 `0x2000` |

> 以上地址都是举例，真实地址会随运行环境变化。我们这里只关心“关系”，不关心具体十六进制数值。

如果写：

```cpp
*p = 99;
```

就会改变 `x` 的值，因为 `p` 保存了 `x` 的地址。

由此引出本篇核心问题：**给函数传入 `x`，和传入 `&x`，它会得到什么？**

---

## 5. 第一种：值传递——函数得到一份独立的值

### 5.1 先看一个只有一行的函数

```cpp
void change(int a)
{
    a = 99;
}
```

主函数调用它：

```cpp
int x = 10;
change(x);
```

问题：调用后 `x` 是 99 吗？

**不是，`x` 仍然是 10。**

原因不是“函数没有运行”，而是：`change(int a)` 的形参 `a` 是一个**新的 `int` 对象**，调用时使用 `x` 的值来初始化它。

### 5.2 把这个过程画成一张表

假设执行到 `change(x)` 时：

| 时刻 | `main()` 中的 `x` | `change()` 中的 `a` |
|---|---:|---:|
| 调用前 | 10 | 还不存在 |
| 刚进入函数 | 10 | 10（从 `x` 复制而来） |
| 执行 `a = 99;` | 10 | 99 |
| 函数结束后 | **10** | 形参生命周期已结束 |

这里更适合想象为两个独立的储物柜：

```text
main 的储物柜 x          change 的储物柜 a
    [ 10 ] ──复制 10──►     [ 10 ]
                                │
                             修改为 99
                                ↓
    [ 10 ]                  [ 99 ]
```

**重要**：这是普通 `int` 值传递的结果。函数内部操作的是自己的 `a`，没有拿到外面 `x` 的地址。

### 5.3 用课程的“交换两个数字”例子检查

```cpp
#include <iostream>

void swap_by_value(int a, int b)
{
    int temp = a;
    a = b;
    b = temp;
}

int main()
{
    int x = 1;
    int y = 2;

    swap_by_value(x, y);
    std::cout << "x=" << x << ", y=" << y << '\n';
    return 0;
}
```

输出：

```text
x=1, y=2
```

我们追踪函数内部：

| 执行步骤 | `x` | `y` | 形参 `a` | 形参 `b` | `temp` |
|---|---:|---:|---:|---:|---:|
| 函数开始 | 1 | 2 | 1 | 2 | 未声明 |
| `int temp = a;` | 1 | 2 | 1 | 2 | 1 |
| `a = b;` | 1 | 2 | 2 | 2 | 1 |
| `b = temp;` | 1 | 2 | 2 | 1 | 1 |
| 函数结束 | **1** | **2** | 已结束 | 已结束 | 已结束 |

函数里的 `a`、`b` 的确交换成功了，但它们是复制出来的形参，不是外面的 `x`、`y`。

### 5.4 Python 对照

```python
def change(a):
    a = 99

x = 10
change(x)
print(x)  # 10
```

结果相同，但原因不能完全画等号：

- C++ 的 `int a`：创建一个独立的整型形参，用传入值初始化。
- Python 的 `a`：函数里的名字最初绑定到传入的对象，`a = 99` 又让名字重新绑定到另一个对象。

你先记住：**这两个例子都不会修改外部的 `x`；但 C++ 的值类型和 Python 的对象绑定不是同一种底层机制。**

## 6. 第二种：指针传参——把原变量的地址交给函数

前面我们已经知道：想通过指针修改一个变量，需要先得到它的地址。

```cpp
int x = 10;
int* p = &x;
*p = 99; // x 变为 99
```

那么，让函数接收地址，不就能从函数里修改原变量了吗？

### 6.1 最简单的一次修改

```cpp
void change(int* p)
{
    *p = 99;
}

int main()
{
    int x = 10;
    change(&x);
    // 现在 x 是 99
    return 0;
}
```

对比上一节：

```cpp
change(x);   // 值传递版本：交出的是数字 10
change(&x);  // 指针参数版本：交出的是 x 的地址
```

**注意**：这两行对应两种不同的函数定义，是为了帮助比较，不要在同一程序中把两者混用。

### 6.2 按三步理解 `change(&x)`

假设 `x` 的地址为 `0x1000`：

**第一步：在 `main()` 里计算参数**

```cpp
&x  // 得到 0x1000
```

**第二步：函数获得这个地址**

```cpp
void change(int* p)
```

此时函数内的 `p` 保存 `0x1000`。虽然 `p` 是一个**独立的指针形参变量**，但它和原来 `&x` 指向同一个位置。

**第三步：执行 `*p = 99;`**

```text
main()                       change() 内
x 住在地址 0x1000               p 保存 0x1000
       [10] ◄──── *p 写入 ─────── p
       [99]
```

修改的就是原本的 `x`，所以函数返回后 `x` 仍然是 99。

### 6.3 再完成截图里的交换任务

```cpp
#include <iostream>

void swap_by_pointer(int* a, int* b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main()
{
    int x = 1;
    int y = 2;

    swap_by_pointer(&x, &y);
    std::cout << "x=" << x << ", y=" << y << '\n';
    return 0;
}
```

输出：

```text
x=2, y=1
```

追踪每一句：

1. `&x` 是 `x` 的地址，传给 `a`；`&y` 是 `y` 的地址，传给 `b`。
2. `int temp = *a;`：取出 `x` 的值 1，保存到 `temp`。
3. `*a = *b;`：把 `y` 的值 2 写入 `x`。
4. `*b = temp;`：把 `temp` 的值 1 写入 `y`。
5. 最终 `x=2`、`y=1`。

### 6.4 为什么这也被叫作“地址传递”？

课程里的称呼是“地址传递”，因为调用时交给函数的确实是地址。

但请把机制分成两层：

- `int* a`：**把地址复制一份给指针形参 `a`**。指针形参 `a` 本身仍然是独立变量。
- `*a`：**通过这个地址访问原来的对象**，所以可以影响外部的 `x`。

现在先把这两层分清即可，不用进一步研究“指针本身能否换指向”或二级指针；那些内容留在本篇末尾的拓展预告。

### 6.5 安全提示与常见使用场景

```cpp
void print_if_present(const int* p)
{
    if (p == nullptr) {
        return;
    }
    std::cout << *p << '\n';
}
```

指针参数比较常见于：

- 可能传入空指针的场景（此时先检查 `nullptr`）。
- 接收数组元素的起始地址。
- C 接口、系统接口，以及以后接触的底层内存缓冲区。

**安全前提**：不是任意地址都能解引用。`p` 必须指向仍然存在、可合法访问的对象；`nullptr` 和悬空指针不能解引用。

# 第三部分：数组作为函数参数

## 7. 从你已经学过的数组开始

你之前写过：

```cpp
int arr[5] = {10, 20, 30, 40, 50};
```

这是一个真正的数组对象，内部有五个相邻排列的 `int` 元素。

假设 `int` 在你的电脑上占 4 字节，数组起始地址是假设的 `0x1000`：

```text
下标       arr[0]     arr[1]     arr[2]     arr[3]     arr[4]
数值         10         20         30         40         50
地址       0x1000     0x1004     0x1008     0x100C     0x1010
           └──────────连续的 5 个 int 元素─────────────┘
```

数组对象占据：

```cpp
sizeof(arr)      // 常见结果 20 字节
sizeof(arr[0])   // 常见结果 4 字节
```

为什么 `20`？因为 5 个元素，每个 4 字节：`5 × 4 = 20`。

**这一步很重要**：数组本身包含真实元素。它**不是**一个“只存储首元素地址的指针变量”。

## 8. 想把整个数组交给一个函数，怎么写？

我们先只做一件简单的事情：把数组的第一个元素改成 99。

```cpp
#include <iostream>

void change_first(int arr[])
{
    arr[0] = 99;
}

int main()
{
    int data[3] = {10, 20, 30};
    change_first(data);
    std::cout << data[0] << '\n';
    return 0;
}
```

输出：

```text
99
```

**观察**：虽然调用时没有写 `&data[0]`，函数内部仍然改动了原来的 `data[0]`。

这是因为：在这种普通函数调用场景中，数组 `data` 通常会提供**指向首元素的地址**；接收数组的形参 `arr[]`，实际是按指针参数处理的。

先用简单模型理解：

```text
main() 中的数组 data： [10] [20] [30]
                             ▲
                             │
函数 change_first 的 arr 记录首元素地址
          arr[0] = 99  ──────┘

结果：                  [99] [20] [30]
```

### 8.1 课程里三种写法为何都能用？

```cpp
void func1(int arr[]);
void func2(int arr[10]);
void func3(int* arr);
```

现在你只需要知道：**对于普通一维数组函数形参，这三种写法最后都按 `int*` 参数来使用。**

- `int arr[]`：告诉读代码的人“这里打算接收数组”。
- `int arr[10]`：看上去写了 10，但这里的 `10` **不让函数自动获得或检查传入数组的长度**。
- `int* arr`：明确写成了指针参数。

**例外先不展开**：将来学习“数组引用”“模板”时，可以让函数保留数组长度。本节只研究截图中的这三种普通写法。

### 8.2 为什么函数里 `sizeof(arr)` 从 20 变成 8？

先看完整例子：

```cpp
#include <iostream>

void inspect(int arr[5])
{
    std::cout << "函数中: " << sizeof(arr) << '\n';
}

int main()
{
    int data[5] = {10, 20, 30, 40, 50};

    std::cout << "main中: " << sizeof(data) << '\n';
    inspect(data);
    return 0;
}
```

在常见 Windows 64 位、`int` 4 字节、指针 8 字节的环境中，输出类似：

```text
main中: 20
函数中: 8
```

对照理解：

| 位置 | 表达式 | 这里它是什么？ | `sizeof` 结果（此环境） |
|---|---|---|---:|
| `main()` | `data` | 真正的 5 元素数组 | 20 字节 |
| `inspect()` | `arr` | 指向 `int` 的指针形参 | 8 字节 |

原因很直接：**进入函数后，形参 `arr` 已经不是外面那个完整数组对象，而是用来访问其元素的指针。**

G++ 可能提示 `sizeof` 用在这种数组形参上有问题——这正是因为初学者很容易误以为它还能得到整个数组的大小。

> “数组退化为指针”是课程经常使用的口头说法。你只需先记住上面的现象与原因；更正式的术语叫“数组到指针的转换”“数组形式的函数形参调整为指针形参”。这些是**对特定表达式和形参位置的规则**，并不是“所有数组本质上都是指针”。

## 9. 既然只传了地址，函数怎么知道有多少个元素？

答案：**单凭这个 `int*` 形参，它不知道。**

因此，课程建议把数组长度一起传给函数：

```cpp
#include <iostream>

void print_array(const int* arr, int length)
{
    for (int i = 0; i < length; ++i) {
        std::cout << arr[i] << ' ';
    }
    std::cout << '\n';
}

int main()
{
    int data[] = {10, 20, 30, 40, 50};
    int count = static_cast<int>(sizeof(data) / sizeof(data[0]));

    print_array(data, count);
    return 0;
}
```

输出：

```text
10 20 30 40 50
```

这里没有新魔法：

- `arr`：告诉函数**数据从哪里开始**。
- `length`：告诉函数**有多少个元素可以处理**。
- `arr[i]`：按照下标逐个访问。

`const int*` 表示这个函数只读取数组元素，不通过这个指针修改它们。你在之前的 `const` 指针章节已经见过它；这里不必深入复习。

另外，`sizeof(data)/sizeof(data[0])` 应该在**数组仍然是真正数组的地方**使用；如果 `data` 已是一个 `int*` 指针，就不能靠这个公式求数组长度。

### 9.1 与 Python `list` 有什么区别？

```python
numbers = [10, 20, 30]

def print_numbers(xs):
    for x in xs:
        print(x)

print_numbers(numbers)
```

Python 的列表对象有长度信息，函数里可以 `len(xs)`。C++ 原始数组交给上述 `int*` 形参后，**只保存起始地址的指针自身并不知道有多少元素**。

你之后学到 `std::vector` 时，它和 Python 列表更接近：容器会记录大小，通常不必手工把长度当作另一个参数。

# 第四部分：引用及引用传参

## 10. 先别急着说“引用传参”：什么是引用？

你已经知道普通指针：

```cpp
int x = 10;
int* p = &x;
```

通过 `*p`，可以访问原来的 `x`。

C++ 还提供一种用法：让另一个名字直接对应**同一个现有对象**。这就是我们当前学习的引用（reference）。

```cpp
int x = 10;
int& alias = x;
```

可以先把 `alias` 理解为：**变量 `x` 的另一个名字**。

```cpp
alias = 20;
std::cout << x << '\n'; // 20
```

由于 `alias` 和 `x` 指的是同一个 `int` 对象，修改 `alias`，就是在修改 `x`。

### 10.1 用具体数值一步步追踪

```cpp
int x = 10;
int& alias = x;
alias = 20;
x = 30;
```

| 执行结束的位置 | `x` 的值 | 从 `alias` 读取的值 |
|---|---:|---:|
| `int& alias = x;` | 10 | 10 |
| `alias = 20;` | 20 | 20 |
| `x = 30;` | 30 | 30 |

这和“创建两个相互独立的 `int` 变量”不一样：

```cpp
int x = 10;
int y = x; // y 是独立的新 int，保存了 10
```

只改 `y` 不会改 `x`；而修改引用 `alias` 会改 `x`。

### 10.2 `&` 为什么这里不是取地址？

符号相同，位置不同，用法不同：

```cpp
int* p = &x;  // 右边的 &x：获取 x 的地址
int& r = x;   // 左边类型声明中的 &：声明 r 是引用
```

**不需要现在死记符号优先级**，先看它是不是写在类型声明中。

### 10.3 为什么引用不能“重新指向”其他变量？

```cpp
int x = 10;
int y = 99;
int& r = x;

r = y;
```

最后发生的是：**把 99 赋给 `x`**，而不是把 `r` 改成引用 `y`。

此时 `x` 是 99，`r` 仍然引用 `x`。

通俗地说：引用在初始化时就绑定好对象；之后普通的 `=` 是**给被引用的对象赋值**。

### 10.4 引用必须初始化吗？能不能为空？

对于当前学习的普通引用：

```cpp
int x = 10;
int& r = x;  // 正确

// int& bad;    // 错误：没有初始化引用
```

它不能像指针那样写成 `int* p = nullptr;` 来表达“现在谁也不指向”。

你可以把它记成：

- 指针：更像一张**可以换地址的纸条**，也可以暂时为空。
- 引用：更像已经给某个现有对象起了**第二个名字**。

这只是理解模型。引用也可能因为原对象生命周期结束而悬空，不能因此认为引用在所有情况下都绝对安全。

## 11. 引用传参：不用写 `&x`，也可以修改原变量

现在已经知道 `int& r = x` 表示引用同一个 `x`。

那么可以让函数参数也这样写：

```cpp
void change(int& a)
{
    a = 99;
}

int main()
{
    int x = 10;
    change(x);
    // x 变成 99
    return 0;
}
```

**差别在定义函数时：**

```cpp
void change(int a)   // 普通值形参：独立的 int
void change(int& a)  // 引用形参：关联原来的 int 对象
```

调用时两者都可能是 `change(x)`，但函数签名中的 `&` 决定了不同效果。（它们也可以作为重载时出现歧义；这里只是并列对比，不要在一个源文件中同时定义并调用这两个同名版本。）

### 11.1 再看课程交换变量的第三种写法

```cpp
#include <iostream>

void swap_by_reference(int& a, int& b)
{
    int temp = a;
    a = b;
    b = temp;
}

int main()
{
    int x = 1;
    int y = 2;

    swap_by_reference(x, y);
    std::cout << "x=" << x << ", y=" << y << '\n';
    return 0;
}
```

输出：

```text
x=2, y=1
```

因为函数体中的 `a` 对应调用者的 `x`，`b` 对应调用者的 `y`。

```text
main()                   swap_by_reference()
  x = 1  ◄──────────────  a 是 x 的引用
  y = 2  ◄──────────────  b 是 y 的引用

在函数中给 a、b 赋值，就是修改 x、y。
```

### 11.2 与指针写法放在一起

```cpp
// 指针形参：函数体要写 *a，调用时通常传 &x
void swap_pointer(int* a, int* b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

// 引用形参：函数体直接写 a，调用时传 x
void swap_reference(int& a, int& b)
{
    int temp = a;
    a = b;
    b = temp;
}
```

两者都能交换调用者的两个整数，**只是表达方式不同**。尤其不要把“引用不需要写 `*`”理解成“引用不访问内存”。

## 12. 一次看懂值、指针、引用三种传参方式

对同一个目标：让函数把 `x` 的值改成 99。

| 方式 | 函数怎么写？ | 怎么调用？ | `x` 会变成 99 吗？ | 为什么？ |
|---|---|---|---|---|
| **值传递** | `void f(int a){ a=99; }` | `f(x);` | **不会** | 改的是独立形参 `a` |
| **指针传参** | `void f(int* a){ *a=99; }` | `f(&x);` | **会** | `a` 保存 `x` 的地址，通过 `*a` 写回 |
| **引用传参** | `void f(int& a){ a=99; }` | `f(x);` | **会** | `a` 绑定到原来的 `x` |

用一句话记忆：

- **值传递：复制值，我改我的。**
- **指针传参：拿到地址，我沿着地址改你的。**
- **引用传参：使用另一个名字，改的就是你。**

### 12.1 函数中修改外部变量，哪一种最常用？

对于本篇的普通 `int`：

- 函数只需要一个数字，不必改变调用者：先选 `int` 值参数。
- 函数明确需要修改调用者的一个现有对象：可以选择 `int&` 引用参数。
- 参数可能没有对应对象（要允许 `nullptr`），或调用底层 C 接口：指针参数更适合。

这只是当前阶段的直观选型。以后处理大型对象时还会学习 `const` 引用；这部分现在不抢先展开。

## 13. 做一个完整实验：你可以在 VS Code 里打断点

这段代码可以直接复制编译，同时验证三种传参方式与数组传参。

```cpp
#include <iostream>

void by_value(int a)
{
    a = 99;
}

void by_pointer(int* a)
{
    *a = 99;
}

void by_reference(int& a)
{
    a = 99;
}

void change_array(int arr[], int length)
{
    if (length > 0) {
        arr[0] = 100;
    }
}

int main()
{
    int x = 10;

    by_value(x);
    std::cout << "after value: " << x << '\n';

    by_pointer(&x);
    std::cout << "after pointer: " << x << '\n';

    by_reference(x);
    std::cout << "after reference: " << x << '\n';

    int nums[3] = {1, 2, 3};
    change_array(nums, 3);
    std::cout << "after array: " << nums[0] << '\n';

    return 0;
}
```

预期输出：

```text
after value: 10
after pointer: 99
after reference: 99
after array: 100
```

在 Windows PowerShell 中：

```powershell
g++ -std=c++17 -Wall -Wextra -g -O0 .\function_params.cpp -o .\function_params.exe
.\function_params.exe
```

**建议这样打断点**：

1. 在 `by_value` 的 `a = 99` 上停住，查看函数中的 `a` 和外面的 `x`。
2. 在 `by_pointer` 的 `*a = 99` 上停住，查看 `a` 保存的地址是否等于 `&x`。
3. 在 `by_reference` 的 `a = 99` 上停住，观察 `x` 是否跟着改变。
4. 在 `change_array` 中修改 `arr[0]`，观察主函数的 `nums[0]`。

不要强求通过打印地址判断引用在机器底层“占几个字节”：我们当前需要理解的是**语言层面的绑定关系和修改效果**。

## 14. Python 对照：哪些地方相似，哪些地方不能直接套用？

你已经熟悉 Python，先看两种常见情况。

### 14.1 给整数形参重新赋值

```python
def change(n):
    n = 99

x = 10
change(x)
print(x)  # 10
```

这与 C++ `void f(int n) { n = 99; }` 的**可观察效果相似**，但 Python 是局部名字重新绑定对象，C++ 普通 `int` 值参数是独立对象。

### 14.2 修改可变列表的元素

```python
def change(xs):
    xs[0] = 99

numbers = [1, 2, 3]
change(numbers)
print(numbers)  # [99, 2, 3]
```

Python 函数里的 `xs` 和调用者的 `numbers` 最初引用同一个列表对象，因此修改列表元素会被外部看到。

这在**效果上**类似于 C++ 函数通过数组首元素地址修改 `arr[0]`，但不是说“Python 实际上传的就是 C++ 的 `int*`”。

| Python 经验 | C++ 中对应的学习点 |
|---|---|
| 给整数形参重新赋值，外面不变 | 普通 `int` 值传递时外面不变 |
| 修改同一个列表对象的元素，外面会变 | 指针或数组形参可以访问并修改外面对象 |
| Python 无须显式声明指针类型 | C++ 用 `int*`、`int&` 明确表达访问方式 |
| Python `len(list)` | C++ `int*` 参数通常要额外提供长度 |

## 15. 教程截图中容易混淆的地方（学完前面再看）

以下是对课程**教学简化说法**的补充，并不是要求你现在学习更多高级内容。

### 15.1 “值传递完全无法影响外部”怎么理解？

对于截图中的 `int a`，确实不影响调用者的 `int x`。但以后你会看到**把指针本身按值传入**：

```cpp
void f(int* p)
{
    *p = 99;
}
```

这也复制了一个参数值，只不过复制的是**地址**；通过地址访问原对象，因此原对象可以变化。

所以要区分“形参变量是不是独立副本”和“形参能够访问什么对象”。本节理解到这里就够了。

### 15.2 “数组就是首元素地址”准确吗？

不准确。`int data[5]` 是完整的数组对象，不是单独一个地址变量。

在调用 `print_array(data, 5)` 这种场合，可以把数组提供的首元素地址作为函数形参的指针值。**数组本身是数组，作为参数的指针才是指针。**

### 15.3 “在形参中写 `arr[10]`，函数就一定收到 10 个数？”

不一定。这一维数组形参仍是指针性质，`[10]` 不自动为你做安全检查。长度最好在调用时明确传入，且必须确保它不超过实际元素个数。

### 15.4 “引用是不是指针的另一种写法？”

不是一回事。你现在只要记住：

- 指针变量可以保存地址，正常使用时可以换成别的有效地址，也可以设为 `nullptr`。
- 引用一旦绑定某个对象，普通赋值不会使它重新绑定；普通引用不能设为一个空引用。
- 两者都能用于访问原对象，写法不同。

### 15.5 “函数传参都发生在栈上吗？”

不一定。编译器可能把形参放在寄存器、栈上，或通过优化采用其他实现。**不用先背具体放在哪个硬件位置**；本篇讨论的是 C++ 语言保证的语义：有没有独立的值参数、有没有地址、是否绑定原对象。

## 本节最终速记

```text
【函数形式】
void：不返回结果值；可以使用 return; 提前结束
()：没有参数时也要写
函数嵌套调用：一个函数可以调用另一个函数

【普通整数参数】
void f(int a)   → 拿到一份值，改 a 不改外面的 x
void f(int* a)  → 拿到 x 的地址，改 *a 就是改 x
void f(int& a)  → a 是 x 的引用，改 a 就是改 x

【数组参数】
int data[5]     → data 是真实数组对象，含五个 int
void g(int arr[]) → 函数中的 arr 按 int* 参数使用
                   只知道从哪里开始，不自动知道总长度
                   所以通常一起传长度
```

**学完本篇的达标标准**：不用背“形参调整”等术语，也能用自己的话解释为什么值传递不能交换外面的整数，而指针和引用可以；为什么函数里的 `sizeof(arr)` 不是整个数组字节数。达到这个程度，再继续函数重载、默认参数、`const` 引用就比较顺畅。
