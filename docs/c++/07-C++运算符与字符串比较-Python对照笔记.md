## 0. 先认识“运算符”

运算符（Operator）是一种表示**运算或操作**的符号，例如：

```cpp
int a = 10;
int b = 5;
int sum = a + b;
```

- `=`：赋值/初始化写法中使用的符号（在声明中此例执行初始化）；
- `+`：加法运算符；
- `a`、`b`：运算符的操作数（Operand）。

与 Python 相同，大部分运算符都是表达式的一部分；不同点在于 C++ 还有 `++`、`--`、`?:` 等 Python 没有的写法，部分符号对不同类型还可能有不同的行为。

## 1. 算术运算符（Arithmetic Operators）

根据课程第一张截图：

| 运算符 | 术语 | 示例 | 结果或说明 | Python 对照 |
|---|---|---|---|---|
| `+` | 一元正号 | `+3` | `3` | `+3` |
| `-` | 一元负号 | `-3` | `-3` | `-3` |
| `+` | 加 | `10 + 5` | `15` | 相同 |
| `-` | 减 | `10 - 5` | `5` | 相同 |
| `*` | 乘 | `10 * 5` | `50` | 相同 |
| `/` | 除 | `10 / 5` | `2` | **需注意整数除法规则不同** |
| `%` | 取余 | `10 % 3` | `1` | 写法相同；负数规则可能不同 |
| `++a` | 前置自增 | `a=2; b=++a;` | `a=3, b=3` | 没有 `++` |
| `a++` | 后置自增 | `a=2; b=a++;` | `a=3, b=2` | 没有 `++` |
| `--a` | 前置自减 | `a=2; b=--a;` | `a=1, b=1` | 没有 `--` |
| `a--` | 后置自减 | `a=2; b=a--;` | `a=1, b=2` | 没有 `--` |

### 1.1 C++ 的整数除法与 Python 不同

```cpp
std::cout << 7 / 2 << '\n';      // 3：两个操作数都是 int
std::cout << 7.0 / 2 << '\n';    // 3.5：存在浮点操作数
std::cout << 7 / 2.0 << '\n';    // 3.5
```

对比 Python：

```python
print(7 / 2)    # 3.5
print(7 // 2)   # 3
```

C++ 中两个整数相除，结果按**向 0 截断**处理。例如 `-7 / 2` 的结果是 `-3`；Python 的 `-7 // 2` 则是 `-4`（向下取整）。

📌 **延伸：负数取余**

- C++：`-7 % 3` 的结果是 `-1`；
- Python：`-7 % 3` 的结果是 `2`。

这是两种语言对整数商的舍入方式不同所导致的。请勿把 Python 的 `//` 和 `%` 的负数规则直接照搬到 C++。

### 1.2 `++` 的前置与后置：究竟差在哪里？

```cpp
int a = 2;
int b = ++a;   // 先将 a 加 1，再把新值用于表达式
// a = 3, b = 3
```

```cpp
int a = 2;
int b = a++;   // 表达式先使用 a 的旧值，再让 a 加 1
// a = 3, b = 2
```

**口诀：前置先改后用；后置先用后改。** `--` 同理。

Python 没有 `a++` / `++a`，常用：

```python
a += 1
```

⚠️ **延伸：不要写容易产生未定义行为或难以判断的复杂自增表达式**，如把同一变量的多个 `++` 塞进一条表达式。初学阶段每次单独写一行最清楚。

### 1.3 算术操作示例

```cpp
#include <iostream>

int main() {
    int a = 10;
    int b = 3;
    std::cout << "a + b = " << a + b << '\n';  // 13
    std::cout << "a / b = " << a / b << '\n';  // 3
    std::cout << "a % b = " << a % b << '\n';  // 1
    return 0;
}
```

## 2. 赋值运算符（Assignment Operators）

课程第二张截图介绍：

| 运算符 | 含义 | 示例 | 最终结果 | Python 对照 |
|---|---|---|---|---|
| `=` | 赋值 | `int a=2; a=3;` | `a=3` | `a=3`（但赋值语义不同） |
| `+=` | 加后赋值 | `a=0; a+=2;` | `a=2` | 相同写法 |
| `-=` | 减后赋值 | `a=5; a-=3;` | `a=2` | 相同写法 |
| `*=` | 乘后赋值 | `a=2; a*=2;` | `a=4` | 相同写法 |
| `/=` | 除后赋值 | `a=4; a/=2;` | `a=2` | 相同写法，但整数规则不同 |
| `%=` | 取余后赋值 | `a=3; a%=2;` | `a=1` | 相同写法 |

例如：

```cpp
int a = 10;
a += 5;  // 相当于 a = a + 5；a 变为 15
a *= 2;  // a 变为 30
```

**Python 对照：**

```python
a = 10
a += 5
a *= 2
```

⚠️ **补充区分：** `int a = 10;` 是声明并初始化变量；`a = 20;` 才是对已有变量赋值。前一篇你已学过：Python 的普通 `=` 主要是让名字绑定对象，而 C++ 普通值类型的赋值通常是修改已有对象中的值。对于 C++ 类类型，赋值运算符还能有自定义语义。

## 3. 比较运算符（Relational / Equality Operators）

课程第三张截图：比较运算符将两个值进行比较，通常得到一个 `bool` 结果。

| 运算符 | 含义 | 示例 | 结果 |
|---|---|---|---|
| `==` | 等于 | `4 == 3` | `false`（默认输出 `0`） |
| `!=` | 不等于 | `4 != 3` | `true`（默认输出 `1`） |
| `<` | 小于 | `4 < 3` | `false` |
| `>` | 大于 | `4 > 3` | `true` |
| `<=` | 小于等于 | `4 <= 3` | `false` |
| `>=` | 大于等于 | `4 >= 1` | `true` |

```cpp
#include <iostream>

int main() {
    int a = 4, b = 3;
    std::cout << (a == b) << '\n';                  // 0
    std::cout << std::boolalpha << (a != b) << '\n'; // true
}
```

**不要把 `=` 和 `==` 混淆：**

- `a = b`：赋值；
- `a == b`：比较是否相等。

Python 中 `==` 也表示值比较；Python 还有 `is` 用于判断是否为同一个对象，而 C++ 的原生指针比较和 Python `is` 并不是一套完全相同的模型。

📌 **延伸：浮点比较**：不要总是假定 `0.1 + 0.2 == 0.3` 为真，C++ `double` 与 Python `float` 都可能受二进制浮点近似误差影响。需要时使用误差容限比较。

## 4. 重点：为什么两种字符串的比较方式不同？

课程第四、五张截图强调了两类写法：

### 4.1 C 风格字符串：`char[]` 与 `const char*`

```cpp
char s1[] = "hello";       // 拥有独立存储空间的字符数组
const char* s2 = "hello";  // 指向字符串字面量的指针
```

两个变量都能通过 `std::cout` 打印出 `hello`，但 `s1 == s2` **不会按字符内容逐一比较**。

发生的事情是：在这样的比较表达式中，`s1` 通常会退化为指向首元素的指针，然后进行**指针值（地址）比较**。

```cpp
std::cout << (s1 == s2) << '\n'; // 两个不同存储位置，结果为 0
```

⚠️ **截图中的说法需要澄清 ①**：

课程使用 `char* s = "hello";` 来表示指向字面量的指针。**现代标准 C++（你使用的 C++17）应写成 `const char* s = "hello";`**，因为字符串字面量不可修改，不能用普通 `char*` 直接初始化。

⚠️ **截图中的说法需要澄清 ②**：

“C 风格字符串通过运算符比较的是内存地址”是针对**两个 C 风格字符数组/指针参与直接 `==` 比较**的常见情形；不是说所有涉及字符串字面量的表达式都必然如此。特别地，两个相同字面量在程序中是否复用存储，不应作为比较内容的依据。

### 4.2 C 风格字符串正确比较内容：`std::strcmp`

使用标准库 `<cstring>`：

```cpp
#include <iostream>
#include <cstring>

int main() {
    char s1[] = "hello";
    const char* s2 = "hello";

    std::cout << (s1 == s2) << '\n';       // 地址比较，通常/在此为 0
    std::cout << std::strcmp(s1, s2) << '\n'; // 内容相同，输出 0
    return 0;
}
```

`std::strcmp(a, b)` 比较以 `\0` 结束的 C 风格字符串，按字符序列的字典序进行比较：

| 返回结果 | 含义 |
|---|---|
| `< 0` | `a` 的字典序小于 `b` |
| `== 0` | 两者内容相同 |
| `> 0` | `a` 的字典序大于 `b` |

例如：

```cpp
std::strcmp("a", "b"); // 负数
std::strcmp("a", "a"); // 0
std::strcmp("c", "a"); // 正数
```

⚠️ **截图中的说法需要澄清 ③**：

截图将返回值写成 `-1 / 0 / 1`。严格来说，标准只保证**负数 / 零 / 正数**，而**不保证非零返回值一定恰好是 -1 或 1**。因此正确判断方法是：

```cpp
if (std::strcmp(s1, s2) == 0) {
    std::cout << "same content\n";
}
```

### 4.3 C++ 风格字符串：`std::string`

```cpp
#include <string>

std::string s1 = "hello";
std::string s2 = "hello";

bool same = (s1 == s2); // true，按内容比较
```

`std::string` 为 `==`、`!=`、`<` 等运算符提供了字符串内容比较。至少一个操作数是 `std::string` 且存在对应重载时，可以直接与 C 风格字符串内容比较：

```cpp
std::string s5 = "a";
char s6[] = "a";
std::cout << (s5 == s6) << '\n'; // 1
```

**Python 对照：**

```python
"hello" == "hello"   # True，按内容比较
```

`std::string` 的 `==` 更像 Python `str` 的 `==`；而 C 风格指针之间的 `==` 更接近“是不是同一个存储位置”，但不要简单等同于 Python 的 `is`。

### 4.4 三种写法放在一起看

| 写法 | 保存/指向什么 | 如何比较字符串内容 | 能否修改内容 |
|---|---|---|---|
| `char a[] = "abc";` | 一个独立的字符数组 | `std::strcmp(a, b)` | 可以修改数组中的字符（容量有限） |
| `const char* p = "abc";` | 指向字符串字面量的地址 | `std::strcmp(p, q)` | 不可通过 `p` 修改字面量，但 `p` 可以改指向 |
| `std::string s = "abc";` | 标准库字符串对象 | `s == t` | 可以修改内容，也可直接赋新字符串 |

📌 **特别提醒**：`std::strcmp` 的参数必须指向有效、以 `\0` 结束的字符串，不能对任意未终止的字节数组直接调用。

## 5. 逻辑运算符（Logical Operators）

根据课程第六、七张截图：逻辑运算用于组合条件，通常结果为 `bool`。

| 运算符 | 术语 | 规则 | Python 对照 |
|---|---|---|---|
| `!` | 非（NOT） | 真变假、假变真 | `not` |
| `&&` | 与（AND） | 两边都为真才为真 | `and` |
| `\|\|` | 或（OR） | 至少一边为真就为真 | `or` |

```cpp
bool a = true;
bool b = false;

std::cout << std::boolalpha;
std::cout << !a << '\n';       // false
std::cout << (a && b) << '\n'; // false
std::cout << (a || b) << '\n'; // true
```

### 5.1 短路求值（截图之外的实用补充）

C++ 的 `&&` 和 `||` 与 Python `and`、`or` 一样，具有**短路**行为：

- `A && B`：如果 `A` 已经为假，就不再计算 `B`；
- `A || B`：如果 `A` 已经为真，就不再计算 `B`。

```cpp
int n = 0;
if (n != 0 && 10 / n > 1) {
    // n == 0 时，后半部分不会计算，避免除零
}
```

⚠️ 差异：C++ 内建逻辑运算符的结果是 `bool`，Python 的 `and` / `or` 则经常返回某个操作数对象。例如 `"" or "default"` 返回字符串 `"default"`，而不是布尔值。

## 6. 三目（条件）运算符 `?:`（Conditional Operator）

根据课程第八张截图：

```cpp
条件表达式 ? 值1 : 值2
```

含义：条件为真，计算并选用第二个操作数（`值1`）；条件为假，计算并选用第三个操作数（`值2`）。

```cpp
int a = 10;
int b = 20;
int larger = (a > b) ? a : b;
std::cout << larger << '\n'; // 20
```

**Python 对照：**

```python
a = 10
b = 20
larger = a if a > b else b
```

注意语序不同：

- C++：`条件 ? 真值 : 假值`；
- Python：`真值 if 条件 else 假值`。

📌 **延伸**：`?:` 不一定只是“从两个变量中选一个数字”，它是一个表达式；后两项的类型及值类别会影响最终表达式的类型。初学时可先用于简单的同类型分支，复杂业务使用 `if/else` 更容易维护。

## 7. 运算符优先级：先别背完整表

当多个运算符写在同一表达式中时，存在优先级和结合规则。

```cpp
int result = 2 + 3 * 4;      // 14：先乘后加
bool ok = (age >= 18) && (age < 60);
```

现在只需记住：

1. `* / %` 通常先于 `+ -`；
2. 比较运算符与逻辑运算符组合时，**建议显式加括号**；
3. `=` 不等于 `==`；
4. 不要把 `++` 和多个依赖同一变量的操作挤在一起。

`std::cout << ...` 的 `<<` 也可能在整数中表示左移运算符；C++ 通过类型和运算符重载决定它的具体行为。

## 8. 一个综合实验：适合直接放进 VS Code 运行

```cpp
#include <iostream>
#include <string>
#include <cstring>

int main() {
    // 算术 + 赋值
    int a = 7;
    int b = 2;
    std::cout << "int division = " << a / b << '\n';  // 3
    a += 3;
    std::cout << "a = " << a << '\n';                 // 10

    // 前置/后置递增
    int x = 2;
    int before = ++x;
    std::cout << "prefix: " << x << ", " << before << '\n';
    int y = 2;
    int after = y++;
    std::cout << "postfix: " << y << ", " << after << '\n';

    // 比较 + 逻辑
    int age = 21;
    bool adult = age >= 18;
    bool in_range = (age >= 18) && (age < 60);
    std::cout << std::boolalpha;
    std::cout << "adult = " << adult << '\n';
    std::cout << "in_range = " << in_range << '\n';

    // C 风格字符串：区分地址与内容
    char s1[] = "hello";
    const char* s2 = "hello";
    std::cout << "pointer equal = " << (s1 == s2) << '\n';
    std::cout << "content equal = " << (std::strcmp(s1, s2) == 0) << '\n';

    // std::string：可使用 == 比较内容
    std::string s3 = "hello";
    std::cout << "std::string equal = " << (s3 == s1) << '\n';

    // 三目运算符
    int score = 82;
    std::string level = (score >= 60) ? "pass" : "fail";
    std::cout << "level = " << level << '\n';
    return 0;
}
```

在你的 Windows / MSYS2 G++ 环境中，可在该文件所在目录运行：

```powershell
g++ -std=c++17 -Wall -Wextra -g .\operators.cpp -o .\operators.exe
.\operators.exe
```

可以把 `operators.cpp` 换成你保存时实际使用的文件名。建议先独立编译一个 `.cpp`，避免把多个有 `main()` 的练习文件链接在一起。

## 10. 一页总结：与 Python 的关键对应

| 知识点 | C++ | Python | 最容易踩的坑 |
|---|---|---|---|
| 整数除法 | `7 / 2 == 3` | `7 / 2 == 3.5` | C++ 整数除法截断 |
| 取余 | `%` | `%` | 负数规则不完全相同 |
| 自增 | `++a`、`a++` | `a += 1` | 前置/后置返回值不同 |
| 赋值 | `=`、`+=` | `=`、`+=` | 普通变量与名字绑定语义不同 |
| 等于比较 | `==` | `==` | 不等于赋值 `=` |
| 字符串按内容比较 | `std::string ==` 或 `std::strcmp` | `str == str` | 两个 C 字符指针 `==` 不是内容比较 |
| 逻辑与/或/非 | `&&`、`\|\|`、`!` | `and`、`or`、`not` | Python `and/or` 可返回操作数 |
| 三目 | `cond ? a : b` | `a if cond else b` | 语序不同 |

### 学完这一节应该具备的能力

- 读懂基础算术、赋值、比较和逻辑表达式；
- 分辨前置与后置 `++ / --`；
- 能解释为什么 `char[]` 和 `const char*` 不能直接用 `==` 判断字符串内容；
- 能使用 `std::strcmp` 或 `std::string` 完成正确的内容比较；
- 能把 Python 条件表达式改写为 C++ `?:`；
- 能独立编译并运行一个包含上述运算符的示例程序。

> **与之后的 llama.cpp 学习联系**：`%`、位运算和数组索引会出现在量化 Block 的数据处理里；`&&`、`||`、比较和三目表达式会出现在计算路径的条件判断中；理解指针比较与内容比较的不同，是理解底层内存操作的基础。
