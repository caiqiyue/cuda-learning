## 0. 先建立一个直觉：C++ 数组到底是什么？

**数组（Array）** 是一种把**相同类型**的多个元素按顺序放在一起的数据结构。C++ 内置数组的元素在内存中**连续存储**，长度由数组类型确定。

```cpp
int v[5] = {1, 2, 3, 4, 5};
```

可以理解为：

- `int`：每个格子存放一个 `int`；
- `v`：数组的名称；
- `[5]`：一共 5 个格子；
- `{1, 2, 3, 4, 5}`：依次初始化每个格子；
- `v[0]` 到 `v[4]`：通过下标访问对应格子。

**Python 对照：**

```python
v = [1, 2, 3, 4, 5]
print(v[0])
```

```cpp
#include <iostream>
int main() {
    int v[5] = {1, 2, 3, 4, 5};
    std::cout << v[0] << '\n';
}
```

两者在“按下标取元素”这件事上相似，但 **Python `list` 并不是 C++ 内置数组**。Python 列表可以增删元素，元素也可以引用不同类型的对象；C++ 内置数组固定长度，所有元素具有相同的声明类型。

## 1. 数组的定义和初始化

### 1.1 基本语法【课程内容】

```cpp
数据类型 数组名[数组长度];
```

例如：

```cpp
int v[6];   // 声明 6 个 int 元素
```

这并不意味着这些元素自动都是 0。**如果它是函数里的普通局部数组，未显式初始化时，元素的值是不确定的，不应直接读取。**

推荐显式初始化：

```cpp
int a[5] = {1, 2, 3, 4, 5}; // 指定长度并初始化
int b[]  = {1, 2, 3, 4, 5}; // 根据初始值推断长度为 5
int c[5] = {};              // 5 个元素全部为 0
int d[5] = {1, 2};          // 结果为 {1, 2, 0, 0, 0}
```

注意：

```cpp
// int bad[3] = {1, 2, 3, 4};  // 错误：初始值数量超过数组容量
// int no_size[];              // 错误：没有可推断的数组长度
```

### 1.2 为什么要写类型？

因为内存中存放的是二进制数据，类型让编译器知道：一个元素占多少字节、如何解释这些位，以及允许做什么运算。

例如在常见 Windows x64 + G++ 环境中：

```cpp
int a[3]    = {1, 2, 3};       // 通常 3 × 4 = 12 字节
float b[3]  = {1.0f, 2.0f, 3.0f}; // 通常也是 12 字节
```

两者的容量可能相同，但元素按不同格式解释。

## 2. 什么类型能构成数组？【课程内容】

课程列出了基本类型、复合类型、指针类型以及枚举类型。

```cpp
#include <string>

enum Color { RED, GREEN, BLUE };

int ints[]       = {1, 2, 3};
float floats[]   = {1.1f, 2.2f, 3.3f};
double doubles[] = {1.1, 2.2};
char chars[]     = {'a', 'b', 'c'};
bool flags[]     = {false, true, true};
std::string names[] = {"张三", "李四", "王五"};
Color colors[]   = {RED, GREEN, BLUE};

int x = 10, y = 20;
int* addresses[] = {&x, &y}; // 元素是 int* 类型的数组
```

**【重要补充】**“任何类型都能构成数组”是便于入门的概括，并非严格的 C++ 规则。例如，不能创建 `void` 元素的数组、引用数组或函数数组。现在只要记住：**数组里的每个元素必须有一致且合法的元素类型。**

Python 对比：

```python
v = [1, "hello", True]  # Python list 可以混放不同类型的对象引用
```

C++ 内置数组不允许像这样直接混合不同的元素类型。

## 4. 特点二：连续、按顺序存储【课程内容】

假设：

```cpp
int v[5] = {1, 2, 3, 4, 5};
```

并假设一个 `int` 占 4 字节，首元素地址为 `0x1000`：

```text
内存地址         0x1000   0x1004   0x1008   0x100C   0x1010
元素下标           [0]      [1]      [2]      [3]      [4]
元素的值             1        2        3        4        5
                 └────────── 连续存储 ──────────────┘
```

**记住：下标增加 1，不是地址一定加 1 字节，而是向后移动一个元素的大小。**

```cpp
#include <iostream>

int main() {
    int v[5] = {1, 2, 3, 4, 5};
    std::cout << "size of int = " << sizeof(int) << '\n';
    std::cout << "v[0] address = " << &v[0] << '\n';
    std::cout << "v[1] address = " << &v[1] << '\n';
}
```

你当前的平台上 `sizeof(int)` 通常为 4，地址差通常也是 4 字节。每次运行的具体地址可能不同。

### `sizeof` 如何求数组元素个数？

```cpp
int v[5] = {1, 2, 3, 4, 5};

sizeof(v);        // 整个数组占用的字节数：通常 20
sizeof(v[0]);     // 单个元素占用的字节数：通常 4
sizeof(v) / sizeof(v[0]); // 元素个数：5
```

在 C++17 中，还可以使用：

```cpp
#include <iterator>
int v[5] = {1, 2, 3, 4, 5};
auto n = std::size(v);  // 5
```

**【重要补充】** `sizeof(v) / sizeof(v[0])` 适用于**这里这种真正的数组对象**。如果 `v` 已经退化为指针，`sizeof(v)` 得到的是指针大小，不再是整个数组大小。后面会讲。

## 6. 特点四：无自动边界检查，越界很危险【课程内容】

数组长度为 5 时，有效下标为 0 到 4。

```cpp
int v[5] = {1, 2, 3, 4, 5};

// v[10] = 1;             // 越界写入：未定义行为（UB）
// std::cout << v[100];   // 越界读取：未定义行为（UB）
```

C++ 内置数组的 `[]` **没有自动运行时边界检查**。某些情况下编译器会给出警告，但并不保证一定报错；程序可能崩溃、得到乱码，也可能看似正常——都不能说明越界是安全的。

**Python 对比：**

```python
v = [1, 2, 3]
print(v[10])   # IndexError
print(v[-1])   # 合法：最后一个元素
```

C++ 内置数组没有 Python 这样的负下标语义：`v[-1]` 通常也是非法的越界访问。

安全一些的现代 C++ 写法：

```cpp
#include <array>
#include <iostream>
#include <stdexcept>

int main() {
    std::array<int, 3> v = {1, 2, 3};
    try {
        std::cout << v.at(10) << '\n';
    } catch (const std::out_of_range&) {
        std::cout << "index out of range\n";
    }
}
```

`.at()` 会在越界时抛出异常，比直接 `[]` 更容易及时发现问题。

## 7. 最容易误解的概念：数组名与指针是什么关系？【重要纠正】

截图中有一句：“数组变量 `v` 本身不存数据，而是记录 `v[0]` 的内存地址。”

**这句话作为入门类比容易记，但从 C++ 语言规则来说不准确。**

正确理解：

```cpp
int v[5] = {1, 2, 3, 4, 5};
```

- `v` **本身是一个数组对象**，类型是 `int[5]`，元素确实属于这个数组对象；
- `v` **不是一个单独存储了首地址的指针变量**；
- 在很多表达式中，数组名 `v` 会**自动转换（array-to-pointer decay）**为指向首元素 `&v[0]` 的指针；
- 但有例外，例如 `sizeof(v)`、`&v` 等场景不会按普通指针那样处理。

看代码：

```cpp
#include <iostream>

int main() {
    int v[5] = {1, 2, 3, 4, 5};
    int* p = v;             // 此处 v 转换成 &v[0]

    std::cout << v[0] << '\n';
    std::cout << *p << '\n';         // 同样得到首元素 1
    std::cout << *(p + 1) << '\n';   // 得到第二个元素 2
    std::cout << sizeof(v) << '\n'; // 整个数组大小：通常 20
    std::cout << sizeof(p) << '\n'; // 指针本身大小：64 位平台通常 8
}
```

### 两种“加一”

```cpp
int v[5] = {1, 2, 3, 4, 5};
int* p = v;

p + 1;        // 指向下一个 int 元素
&v[0] + 1;   // 同样指向 v[1]
```

在当前平台，如果 `int` 是 4 字节，指针加 1 通常等于物理地址向后移动 4 字节。**指针运算按元素类型缩放，不是简单加一个字节。**

### 为什么以后还会看到“数组传给函数就变成指针”？

```cpp
void print_first(const int a[]) {
    // 这里形参 a 实际按 const int* 处理
}
```

这是函数参数的特殊规则。不要据此认为“任何地方的数组都是指针”。

**对比总结：**

| 表达式/对象 | 真实含义 |
|---|---|
| `v` | 数组对象，在许多表达式中可转换成首元素指针 |
| `v[0]` | 第 1 个元素 |
| `&v[0]` | 第 1 个元素的地址 |
| `int* p = v` | 创建**指针变量** `p`，令它指向首元素 |
| `sizeof(v)` | 整个数组的字节数 |
| `sizeof(p)` | 指针变量本身的字节数 |

**Python 类比：**Python `list` 是一个列表对象，变量名通常绑定到它；C++ 内置数组是具有固定大小的数组对象。二者都不是“变量名里面直接装着所有元素”这么简单，但也不能把 Python 名字绑定机制直接等同于 C++ 数组退化规则。

## 8. 范围 `for`：像 Python 那样遍历数组【课程内容】

课程截图中的“高级 for 循环写法”通常称为 **范围 `for`（range-based for）**。

```cpp
int v[] = {1, 2, 3, 4, 5};

for (int x : v) {
    std::cout << x << ' ';
}
```

它会依次取出数组中的每个元素。

Python 对照：

```python
for x in [1, 2, 3, 4, 5]:
    print(x)
```

### `int x` 和 `int& x` 有什么区别？

```cpp
int v[] = {1, 2, 3};

for (int x : v) {
    x *= 10; // 修改的是副本；原数组仍是 {1,2,3}
}

for (int& x : v) {
    x *= 10; // 引用原元素；原数组变成 {10,20,30}
}
```

- `int x`：按值复制当前元素。
- `int& x`：`x` 是当前元素的引用，可直接修改原数组。
- `const int& x`：不复制大对象且不允许通过这个引用修改原元素。

对于一般的只读代码，也可以写：

```cpp
for (const auto& x : v) {
    std::cout << x << '\n';
}
```

**注意：**Python `for x in ...` 中仅给 `x` 重新赋值，并不会自动替换列表中的元素。这一点更接近 C++ 的按值遍历；但两种语言的对象语义并不完全相同。

## 9. 字符数组：为什么 `"hello"` 需要 6 个格子？【课程内容】

```cpp
char s[] = "hello";
```

等价于：

```cpp
char s[] = {'h', 'e', 'l', 'l', 'o', '\0'};
```

内存示意：

```text
下标     0     1     2     3     4      5
内容    'h'   'e'   'l'   'l'   'o'    '\0'
```

`'\0'` 是 **空字符（NUL）**，数值为 0。它标记 C 风格字符串的结束。它**不是**空格 `' '`，也**不是**字符 `'0'`。

```cpp
#include <iostream>
#include <cstring>

int main() {
    char s[] = "hello";
    std::cout << sizeof(s) << '\n';       // 6：含末尾的 '\0'
    std::cout << std::strlen(s) << '\n';  // 5：不含 '\0'
    std::cout << s << '\n';               // hello
}
```

**两种字符数组写法的区别：**

```cpp
char a[] = {'h', 'e', 'l', 'l', 'o'}; // 只有 5 字节，没有 '\0'，不是安全的 C 字符串
char b[] = "hello";               // 6 字节，包含 '\0'
```

不能直接把 `a` 当作以 `\0` 结尾的 C 字符串传给 `strlen`、或直接当 C 字符串输出，否则可能访问数组之外的内存。

### 中文字符为什么特殊？【重要纠正】

课程强调 ASCII 无法表示中文，这没有问题；但“中文不能用 `char` 数组存储”并不严格。

例如在 **UTF-8** 编码下：

```cpp
char s[] = "中文";
```

可以保存 UTF-8 **字节序列**，只是一个汉字通常占多个字节，因此 `sizeof`、`strlen` 统计的不是“汉字个数”。初学阶段处理文本更推荐 `std::string`，但要知道 **`std::string` 的 `size()` 也通常返回字节数，仍不自动等于 Unicode 字符个数**。

Python 对照：Python `str` 以 Unicode 文本语义提供操作，`len("中文")` 通常是 2；C++ 中 UTF-8 `std::string("中文").size()` 通常是 6。

## 10. 多维数组：数组里面再放数组【课程内容】

### 10.1 二维数组

```cpp
int grid[3][3] = {
    {11, 22, 33},
    {44, 55, 66},
    {77, 88, 99}
};
```

可以理解为 3 行、每行 3 个元素：

```text
             第0列   第1列   第2列
第0行         11      22      33
第1行         44      55      66
第2行         77      88      99
```

访问元素：

```cpp
grid[0][0]; // 11
grid[1][2]; // 66
grid[2][1]; // 88
```

**内存实际上按行连续排列（row-major）：**

```text
11, 22, 33, 44, 55, 66, 77, 88, 99
└─ 第0行 ─┘  └─ 第1行 ─┘  └─ 第2行 ─┘
```

```cpp
#include <iostream>
int main() {
    int grid[3][3] = {
        {11, 22, 33},
        {44, 55, 66},
        {77, 88, 99}
    };

    for (const auto& row : grid) {
        for (int x : row) {
            std::cout << x << ' ';
        }
        std::cout << '\n';
    }
}
```

这里的 `row` 是对“一整行数组”的引用，不是 Python 列表对象。

### 10.2 三维数组

```cpp
int cube[2][3][3] = {};
```

可以理解为 **2 组 × 每组 3 行 × 每行 3 列**，总共：

\[
2\times3\times3=18\text{ 个 int 元素}
\]

```cpp
cube[1][2][0] = 100;
```

表示第 2 组、第 3 行、第 1 列（下标全部从 0 开始）。

**Python 对照：**

```python
grid = [[11, 22, 33], [44, 55, 66], [77, 88, 99]]
print(grid[1][2])
```

Python 的嵌套列表是“列表里面包含其他列表对象的引用”，不保证所有数字在一块连续内存里；C++ 原生 `int grid[3][3]` 则是真正的连续二维数组。对于你已经熟悉的 NumPy，`np.ndarray` 的形状与连续布局更接近 C++ 数组，但 NumPy 还支持 stride、视图、非连续数组等额外能力。

## 11. 内置数组、std::array、std::vector 应该怎么选？【拓展】

| 类型 | 长度 | 内存/接口特点 | Python 对照 |
|---|---|---|---|
| `int a[5]` | 固定 | C++ 内置数组；连续存储；接口较少 | 固定大小数据块的直觉 |
| `std::array<int, 5>` | 固定 | 连续存储；有 `.size()`、`.at()` 等方法 | 比内置数组更方便的固定容器 |
| `std::vector<int>` | 可增长 | 动态连续存储；支持 `push_back()` | 更接近 Python `list` 的增删体验 |

示例：

```cpp
#include <array>
#include <vector>

int a[3] = {1, 2, 3};
std::array<int, 3> b = {1, 2, 3};
std::vector<int> c = {1, 2, 3};

// a = b;         // 不合法，且类型不同；内置数组也不能整体赋值
b[0] = 10;
c.push_back(4);   // c 变为 {1,2,3,4}
```

**学习建议**：课程阶段先把内置数组学透，因为你将来阅读 `llama.cpp` 时会遇到大量 C 风格数组和指针；写新的现代 C++ 业务代码时通常优先考虑 `std::array` / `std::vector`。

## 12. 和 llama.cpp / 量化研发有什么联系？【拓展】

以后在量化计算中经常会看到：

```cpp
#include <cstdint>

uint8_t packed_q4[16] = {}; // 16 字节，可用于存放 32 个打包后的 4-bit 值
float scales[4] = {};       // 4 个浮点缩放因子（仅作为练习示意）
```

现在你可以理解：

1. `packed_q4` 是 16 个 `uint8_t` 元素组成的连续数组；
2. `packed_q4[i]` 访问第 `i` 个字节；
3. 如果每个 4-bit 数值占半字节，可以将两个值打包进一个 `uint8_t`；
4. `scales` 的每个元素是一个 `float`；
5. 指针、偏移、Block 结构体和 Tensor 布局都是建立在这样的内存模型之上。

**注意：**这只是演示底层存储概念，并非某个具体 NVFP4 / Q4_0 格式的完整定义。

## 13. 代码实验：把最重要的概念一次跑通

将下面内容保存为 `array_demo.cpp`，在你的 Windows + MSYS2 环境中编译：

```cpp
#include <iostream>
#include <iterator>
#include <cstring>

int main() {
    int v[] = {1, 2, 3, 4, 5};

    // 1. 长度、元素大小与地址
    std::cout << "count = " << std::size(v) << '\n';
    std::cout << "total bytes = " << sizeof(v) << '\n';
    std::cout << "one element bytes = " << sizeof(v[0]) << '\n';
    std::cout << "first = " << v[0] << '\n';
    std::cout << "address first = " << &v[0] << '\n';
    std::cout << "address second = " << &v[1] << '\n';

    // 2. 修改元素：按引用遍历
    for (int& x : v) {
        x += 10;
    }
    for (int x : v) {
        std::cout << x << ' ';
    }
    std::cout << '\n';

    // 3. 字符数组
    char text[] = "hello";
    std::cout << "sizeof(text) = " << sizeof(text) << '\n';
    std::cout << "strlen(text) = " << std::strlen(text) << '\n';

    // 4. 二维数组
    int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}};
    std::cout << "matrix[1][2] = " << matrix[1][2] << '\n';

    return 0;
}
```

## 15. 本节重点速记

- **声明**：`int v[5];` 声明 5 个 `int` 元素。
- **初始化**：`int v[] = {1,2,3};` 推断长度为 3。
- **下标**：从 0 开始；`v[i]` 访问第 `i+1` 个元素。
- **内存**：数组元素按顺序**连续存储**。
- **长度**：内置数组固定，不能像 Python `list` 那样追加。
- **越界**：内置数组 `[]` 不自动检查；越界是未定义行为。
- **元素修改**：`v[0] = 10;` 可以，但类型须兼容。
- **数组与指针**：**数组不是指针**，只是很多表达式中会转换成首元素指针。
- **范围 for**：`for (int x : v)` 复制元素；`for (int& x : v)` 引用元素。
- **C 字符串**：`char s[] = "hello";` 包含末尾 `\0`，共 6 个字节。
- **二维数组**：`int a[3][3]` 按行连续存储；`a[行][列]`。
- **工程衔接**：看懂数组后，再学**指针、引用、`struct` 和内存布局**，就可以进一步读懂量化 Block。

> **一句话总结：**C++ 内置数组是“**固定数量、同一类型、连续存储**”的元素集合。理解它与指针的关系，是以后学习 ggml / llama.cpp 底层数据结构的关键一步。
